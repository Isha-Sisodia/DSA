### Submitted Code
#### Method - 1 Using sort() function
```python
class Solution:
    def getDivisors(self, n):
        ans = []

        for i in range(1, int(n ** 0.5) + 1):
            if n % i == 0:
                ans.append(i)

                if i != n // i:
                    ans.append(n // i)

        ans.sort()
        return ans
```
### Method - 2 without sort
```python
class Solution:
    def getDivisors(self, n):
        # code here
        ans = []
        d2 = []
        for i in range(1,int(n**0.5)+1):
            if n % i == 0:
                ans.append(i)
                if i != n//i:
                    d2.append(n//i)
        for i in range(len(d2)-1,-1,-1):
            ans.append(d2[i])
        return ans
```
