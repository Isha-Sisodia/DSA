class Solution:

        # code here
        a = []
        b = []
        common = []
        for i in range(1, n1 + 1):
            if n1 % i == 0:
                a.append(i)
        for i in range(1, n2 + 1):
            if n2 % i == 0:
                b.append(i)

                if i==j:
                    common.append(i)
        ans  = max(common)
        return ans

# Method 1: Brute Force

## Idea

The GCD cannot be greater than the smaller number.

1. Find the smaller number.
2. Traverse from `1` to `min(n1, n2)`.
3. If a number divides both numbers, store it.
4. The last stored number is the GCD.

---

## Dry Run

```text
n1 = 12
n2 = 18

Minimum = 12

1  -> divides both ✔
2  -> divides both ✔
3  -> divides both ✔
4  -> ✖
5  -> ✖
6  -> divides both ✔
7-12 -> ✖

Answer = 6
```

---

## Code

```python
class Solution:
    def GCD(self, n1, n2):
        ans = 1

        for i in range(1, min(n1, n2) + 1):
            if n1 % i == 0 and n2 % i == 0:
                ans = i

        return ans
```

---

## Time Complexity

```text
O(min(n1, n2))
```

### Space Complexity

```text
O(1)
```

# Method 2: Traverse Backwards

## Idea

Instead of checking from `1` upwards, start from the minimum number and move backwards.

As soon as you find a common divisor, return it.

---

## Dry Run

```text
n1 = 12
n2 = 18

Check 12 ✖
Check 11 ✖
Check 10 ✖
Check 9 ✖
Check 8 ✖
Check 7 ✖
Check 6 ✔

Return 6
```

---

## Code

```python
class Solution:
    def GCD(self, n1, n2):

        for i in range(min(n1, n2), 0, -1):
            if n1 % i == 0 and n2 % i == 0:
                return i
```

---

## Time Complexity

```text
O(min(n1, n2))
```

### Space Complexity

```text
O(1)
```

# Method 3: Euclidean Algorithm (Optimal)

## Observation

Take two numbers:

```text
12 and 18
```

Step 1

```text
18 % 12 = 6
```

Now consider:

```text
12 and 6
```

Step 2

```text
12 % 6 = 0
```

Now the answer is:

```text
6
```

---

## Key Property

The Euclidean Algorithm is based on the following mathematical property:

```text
GCD(a, b) = GCD(b, a % b)
```

This means we can repeatedly replace:

- `a` with `b`
- `b` with `a % b`

until `b` becomes `0`.

The remaining value of `a` is the GCD.

---

## Dry Run

```text
n1 = 48
n2 = 18
```

### Iteration 1

```text
48 % 18 = 12

n1 = 18
n2 = 12
```

### Iteration 2

```text
18 % 12 = 6

n1 = 12
n2 = 6
```

### Iteration 3

```text
12 % 6 = 0

n1 = 6
n2 = 0
```

Loop ends.

**Answer = 6**

---

## Code

```python
class Solution:
    def GCD(self, n1, n2):

        while n2 != 0:
            n1, n2 = n2, n1 % n2

        return n1
```

---

## Understanding This Line

```python
n1, n2 = n2, n1 % n2
```

This is Python's multiple assignment.

It is equivalent to:

```python
temp = n2
n2 = n1 % n2
n1 = temp
```

### Example

Initially:

```text
n1 = 48
n2 = 18
```

Execution:

```python
temp = 18
n2 = 48 % 18 = 12
n1 = 18
```

Now:

```text
n1 = 18
n2 = 12
```

---

## Time Complexity

```text
O(log(min(n1, n2)))
```

### Space Complexity

```text
O(1)
```

# Comparison

| Method | Time Complexity | Space Complexity | Recommended |
|---------|-----------------|------------------|-------------|
| Brute Force | O(min(n1, n2)) | O(1) | ❌ No |
| Backward Traversal | O(min(n1, n2)) | O(1) | ⚠️ Better |
| Euclidean Algorithm | O(log(min(n1, n2))) | O(1) | ✅ Yes |

---

# Interview Tip

Whenever an interviewer asks you to find the GCD of two numbers, the expected solution is the **Euclidean Algorithm** because it is much faster than checking all divisors.

---

# Key Takeaways

- GCD is the largest number that divides both numbers.
- GCD cannot be greater than the smaller number.
- Brute Force checks every possible divisor.
- Backward Traversal starts from the largest possible divisor.
- Euclidean Algorithm uses the property:

```text
GCD(a, b) = GCD(b, a % b)
```

- The Euclidean Algorithm runs in **O(log(min(n1, n2)))**, making it the optimal solution.
