### Method 1 - Not Optimized
```python
class Solution:
    def isPrime(self, n):
        if n == 2 :    #This is unnecessary condition
            return True
        elif n <= 1:
            return False
        else:
            for i in range(2,n):
                if n % i == 0:
                    return False
        return True      
```

class Solution:
    def isPrime(self, n):

            return False

            if n % i == 0:
                return False

        return True

### Optimized Code - 
```python
class Solution:
    def isPrime(self, n):

        if n <= 1:
            return False

        for i in range(2, int(n**0.5) + 1):
            if n % i == 0:
                return False

        return True
```
