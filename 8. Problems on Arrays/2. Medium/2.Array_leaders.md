## Importatnt
### How does else work here?
**In Python, the else belongs to the for loop. It executes only when the loop finishes without encountering break.**
### TLE
```python
class Solution:
    def leaders(self, arr):
        ans = []
        n = len(arr)
        for i in range(n):
            for j in range(i+1,n):
                if arr[i] < arr[j]:
                    break
            else:
                ans.append(arr[i])
        return ans
```
