```python
class Solution:
	def pushZerosToEnd(self, a):
	    n = len(a)
	    temp = [0]*n
	    idx = 0
	    for num in a:
	        if num != 0:
	            temp[idx] = num
	            idx += 1
    	for i in range(n):
    	    a[i] = temp[i]
    	return a
```
### Best Solution - Using two pointers
```python
class Solution:
	def pushZerosToEnd(self, a):
	    j = 0
	    n = len(a)
    	for i in range(n):
    	    if a[i] != 0:
    	        a[j], a[i] = a[i], a[j]
    	        j += 1
    	return a
```
