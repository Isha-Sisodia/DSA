This is a classic Missing Number problem. Since the array contains distinct numbers from 1 to n, with exactly one missing, there are two common approaches.
### Method - 1
```python
class Solution:
    def missingNum(self, arr):
        arr.sort()
        n = len(arr)

        for i in range(n - 1):
            if arr[i + 1] != arr[i] + 1:
                return arr[i] + 1

        return n + 1
```
### or
```python
class Solution:
    def missingNum(self, arr):
        arr.sort()
        n = len(arr)
        for i in range(n):
            if arr[i] != i+1:
                return i + 1
        return n + 1
```
### Method - 2
**1. Using Sum — easiest to understand**

For n numbers from 1 to n, the expected sum is:
```text
n(n+1)//2​
```
Then:

**missing = expected sum − actual sum**

Example - 
```text
arr = [1, 2, 3, 5]

n = 5

Expected sum = 1+2+3+4+5 = 15
Actual sum   = 1+2+3+5   = 11

Missing = 15 - 11 = 4
```
```python
class Solution:
    def missingNum(self, arr):
        n = len(arr) + 1
        
        expected_sum = n * (n + 1) // 2
        actual_sum = sum(arr)
        
        return expected_sum - actual_sum
```

### Method - 3 (2. XOR approach — better for avoiding sum overflow)
```python
class Solution:
    def missingNum(self, arr):
        n = len(arr) + 1
        ans = 0
        
        for i in range(1, n + 1):
            ans ^= i
            
        for x in arr:
            ans ^= x
            
        return ans
```
**How is XOR useful for Missing Number?**
Suppose:
```nums = [0, 1, 2, 4]```

n = 4

The complete range should be:

0, 1, 2, 3, 4

So we want to find 3.

**Now XOR all numbers that ```should``` exist:**

0 ^ 1 ^ 2 ^ 3 ^ 4

**And XOR all numbers ```actually``` present:**

0 ^ 1 ^ 2 ^ 4

Now combine them:

(0 ^ 1 ^ 2 ^ 3 ^ 4)
^
(0 ^ 1 ^ 2 ^ 4)

Because identical numbers cancel:

0 ^ 0 = 0
1 ^ 1 = 0
2 ^ 2 = 0
4 ^ 4 = 0

We're left with:

3

That's the missing number! 🎯
