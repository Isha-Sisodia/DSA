### TLE  (for positives and negative numbers)
```python
class Solution:
    def longestSubarray(self, arr, k):  
        n = len(arr)
        curr_sum = 0
        max_len = 0
        for i in range(n):
            curr_sum = 0
            for j in range(i,n):
                curr_sum += arr[j]
                if curr_sum == k:
                     max_len = max(max_len, j-i+1)
        return max_len
```
- **Positive numbers only** → Sliding Window is excellent
- **Positive + negative numbers** → Prefix Sum + HashMap is the safer O(n) method.
### Method 2: Sliding Window / Two Pointers (but not for negative numbers like in gfg)
```python
class Solution:
    def longestSubarray(self, arr, k):
        left = 0
        curr_sum = 0
        max_len = 0

        for right in range(len(arr)):
            curr_sum += arr[right]

            while curr_sum > k:
                curr_sum -= arr[left]
                left += 1

            if curr_sum == k:
                max_len = max(max_len, right - left + 1)

        return max_len
```
### Method 3: Prefix Sum + HashMap (for positives and negative numbers)
```python
class Solution:
    def longestSubarray(self, arr, k):
        prefix_sum = 0
        max_len = 0
        mp = {}

        for i in range(len(arr)):
            prefix_sum += arr[i]

            if prefix_sum == k:
                max_len = i + 1

            if prefix_sum - k in mp:
                max_len = max(max_len, i - mp[prefix_sum - k])

            if prefix_sum not in mp:
                mp[prefix_sum] = i

        return max_len
```
