### Method - 1
```python
class Solution:
    def largest(self, arr):
        # code here
        largest = arr[0]
        n = len(arr)
        for i in range(n):
            if largest < arr[i]:
                largest = arr[i]
        return largest
```
### Method - 2
```python
class Solution:
    def largest(self, arr):
        arr.sort()
        return arr[len(arr)-1]
```
