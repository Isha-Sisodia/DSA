**Example 1**
```text
Input: nums = [0, 0, 3, 3, 5, 6]
Output: 4

Explanation:
Resulting array = [0, 3, 5, 6, _, _]
There are 4 distinct elements in nums and the elements marked as _ can have any value.
```
**Example 2**
```text
Input: nums = [-2, 2, 4, 4, 4, 4, 5, 5]
Output: 4

Explanation:
Resulting array = [-2, 2, 4, 5, _, _, _, _]
There are 4 distinct elements in nums and the elements marked as _ can have any value.
```

- Given Array must be sorted

```python
a = [2,2,3,3,4,5,5]
```

### another satisfying solution
```python
a = [-3,-2,2,2,3,4,5,5]
count = 0
for i in range(1,len(a)):
    if a[i] == a[i-1]:
        count += 1
    a[i-count] = a[i]
print(len(a) - count)
print(a)
k = len(a) - count
print(a[:k])
```
```
Output -
6
[-3, -2, 2, 3, 4, 5, 5, 5]
[-3, -2, 2, 3, 4, 5]
```

https://www.geeksforgeeks.org/problems/remove-duplicate-elements-from-sorted-array/1
```text
Input: arr[] = [2, 2, 2, 2, 2]
Output: [2]
Explanation: After removing all the duplicates only one instance of 2 will remain i.e. [2] so modified array will contains 2 at first position and you should return array containing [2] after modifying the array.

Input: arr[] = [1, 2, 4]
Output: [1, 2, 4]
Explation:  As the array does not contain any duplicates so you should return [1, 2, 4].
```
```python
class Solution:
    def removeDuplicates(self, arr):
        # code here 
        seen = set(arr)
        b = list(seen)
        b.sort()
        return b
```
