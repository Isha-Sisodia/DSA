
Important - 1. **Prefix - A prefix must always start from index 0.**
### 1. basic question before that
s1 = "apple"
s2 = "application"
Ques - Print the common prefix
```python
s1 = "apple"
s2 = "application"

for i in range(len(s1)):
    if s1[i] == s2[i]:
        print(s1[i])
    else:
        break
```
Output - 
```python
a
p
p
l
```
### 2. Basic Question 
Instead of printing each matching character separately, let's store them in a string.
```python
s1 = "apple"
s2 = "application"

prefix = ""

for i in range(len(s1)):
    if s1[i] == s2[i]:
        prefix += s1[i]
    else:
        break

print(prefix)
```
Output - 
```appl```
