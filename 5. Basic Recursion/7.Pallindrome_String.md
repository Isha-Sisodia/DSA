```text
- In Reverse Array, we swap the elements.
- In Palindrome, we compare the characters.
```
### Method 1 - Using loop
```python
class Solution:
    def isPalindrome(self, s):
        # code here
        i = 0
        j = len(s)-1
        while i < j:      #or while i < len(s) // 2:
            if s[i] != s[j]:
                return False
            i += 1
            j -= 1
        return True
```
### Method 2 - Recursion
```python
class Solution:
    def isPalindrome(self, s):

        def helper(i, j):

            if i >= j:
                return True

            if s[i] != s[j]:
                return False

            return helper(i + 1, j - 1)

        return helper(0, len(s) - 1)
```
