### Method 2  -Using loop
```python
class Solution:
    # Function to return list containing first n fibonacci numbers.
    def fibonacciNumbers(self, n):

        if n == 1:
            return [0]

        ans = [0, 1]

        a = 0
        b = 1
        count = 2

        while count < n:
            c = a + b
            ans.append(c)

            a = b
            b = c

            count += 1

        return ans
```
### Method 3 Using Dp
**Your current code is Memoization (Top-Down DP)**
```python
class Solution:
    #Function to return list containing first n fibonacci numbers.
    def fibonacciNumbers(self,n):
        dp = [-1] * n

        ans = []

        for i in range(n):
            ans.append(self.fib(i, dp))

        return ans
        
    def fib(self,n,dp):
        if n == 0:
            return 0

        if n == 1:
            return 1

        if dp[n] != -1:
            return dp[n]

        dp[n] = self.fib(n-1, dp) + self.fib(n-2, dp)

        return dp[n]
        
```
