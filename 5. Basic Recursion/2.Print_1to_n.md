## Can we solve it without count?
Yes! **Print After recursion**
```python
def printTillN(n):
    if n == 0:
        return

    printTillN(n - 1)
    print(n, end=" ")


n = int(input())
printTillN(n)
```
**Why does this print 1 2 3 4 5?**

Let's dry run for n = 3:
```text
printTillN(3)
    ↓
printTillN(2)
    ↓
printTillN(1)
    ↓
printTillN(0)   ← Base Case

Return

print(1)
Return

print(2)
Return

print(3)
```
Output - 

```1 2 3```
**The reason this works is because of the Call Stack, and a stack follows LIFO (Last In, First Out).**

**Print before recursion**
```python
def fun(n):
    if n == 0:
        return

    print(n)
    fun(n - 1)
```
Output - 

```3 2 1```
## Submitted Code
```python
class Solution:
    def printTillN(self, n):
    	#code here 
    	if n == 0:
    	    return
    	self.printTillN(n-1)    #Important in case of classes
    	print(n, end = " ")
```
## Golden Rule of Recursion
- **Code before the recursive call** executes while going down the recursion tree.
- **Code after the recursive call** executes while coming back up, thanks to the Call Stack (LIFO).
