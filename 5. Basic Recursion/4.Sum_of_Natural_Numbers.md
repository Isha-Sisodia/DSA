# Sum of Natural Numbers

### Submited solution - 
```python
class Solution:
    def NnumbersSum(self, n):
        if n == 0:
            return 0    #important to return 0
        return n + self.NnumbersSum(n-1)
```
## Problem Statement

Given an integer `n`, compute the sum of all natural numbers from **1 to n (inclusive)**.

If `n = 0`, the sum should be `0`.

### Examples

**Input**

```text
n = 6
```

**Output**

```text
21
```

**Explanation**

```text
1 + 2 + 3 + 4 + 5 + 6 = 21
```

---

## Method 1: Using a Loop
```python
n = int(input())

sum = 0

for i in range(1, n + 1):
    sum += i

print(sum)
```
* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(1)`

---

## Method 2: Using Recursion

### Code

```python
def sumN(n):
    if n == 0:
        return 0

    return n + sumN(n - 1)

n = int(input())
print(sumN(n))
```
* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(n)` (Recursion Stack)

---

## Method 3: Using Mathematical Formula (Optimal)

### Formula

The sum of the first `n` natural numbers is:

```text
n × (n + 1)
--------------
      2
```

### Code

```python
n = int(input())

print(n * (n + 1) // 2)
```
* **Time Complexity:** `O(1)`
* **Space Complexity:** `O(1)`

---

# Comparison

| Method    | Time | Space | Recommended                  |
| --------- | ---- | ----- | ---------------------------- |
| Loop      | O(n) | O(1)  | ✅ Good                       |
| Recursion | O(n) | O(n)  | ✅ When recursion is required |
| Formula   | O(1) | O(1)  | ⭐ Best                       |

---

# Interview Tip

* If the problem **explicitly asks for recursion**, use the recursive solution.
* If **no approach is specified**, prefer the **mathematical formula**, as it is the most efficient.
