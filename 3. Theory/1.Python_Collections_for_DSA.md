# 1. List

**Equivalent** - C++: `vector` - Java: `ArrayList`

A dynamic array that: - Stores duplicates - Grows automatically - Allows
indexing - Supports mixed data types

``` python
nums = [1, 2, 3]
nums.append(4)
nums.insert(1, 100)
nums.remove(2)
nums.pop()
print(nums[0])
```

### Important Methods

-   append()
-   extend()
-   insert()
-   remove()
-   pop()
-   clear()
-   sort()
-   reverse()
-   copy()
-   index()
-   count()

### Time Complexity
```text
  Operation   Complexity
  ----------- ------------
  Access      O(1)
  Append      O(1)
  Insert      O(n)
  Delete      O(n)
  Search      O(n)
```
### Practice Problems

-   Two Sum
-   Move Zeroes
-   Rotate Array
-   Merge Intervals

------------------------------------------------------------------------

# 2. Tuple

Equivalent to C++ `pair/tuple`.

Immutable sequence.

``` python
point = (3, 5)
print(point[0])
```

Used for: - Coordinates - Returning multiple values - Dictionary keys

------------------------------------------------------------------------

# 3. Set

Equivalent to: - `unordered_set` - `HashSet`

Stores unique values only.

``` python
s = {1, 2, 3}
s.add(5)
s.remove(2)
print(5 in s)
```

### Methods

-   add()
-   remove()
-   discard()
-   clear()
-   union()
-   intersection()
-   difference()

### Complexity

  Operation   Complexity
  ----------- ------------
  Add         O(1)
  Remove      O(1)
  Search      O(1)

### Practice Problems

-   Contains Duplicate
-   Longest Consecutive Sequence
-   Happy Number

------------------------------------------------------------------------

# 4. Dictionary

Equivalent to: - `unordered_map` - `HashMap`

Stores key-value pairs.

``` python
student = {
    "name": "Isha",
    "age": 20
}

print(student["name"])
```

### Methods

-   get()
-   keys()
-   values()
-   items()
-   pop()
-   update()
-   clear()

### Complexity
```text
  Operation   Complexity
  ----------- ------------
  Insert      O(1)
  Search      O(1)
  Delete      O(1)
```

### Practice Problems

-   Two Sum
-   Frequency Count
-   Group Anagrams

------------------------------------------------------------------------

# 5. deque

``` python
from collections import deque

dq = deque()
dq.append(10)
dq.appendleft(20)
dq.pop()
dq.popleft()
```

Used for: - Queue - BFS - Sliding Window

All end operations are **O(1)**.

------------------------------------------------------------------------

# 6. Counter

``` python
from collections import Counter

nums = [1,2,2,3,3,3]
freq = Counter(nums)
print(freq)
```

Useful methods: - most_common() - elements() - update()

Practice: - Top K Frequent Elements - Majority Element

------------------------------------------------------------------------

# 7. defaultdict

``` python
from collections import defaultdict

d = defaultdict(list)
d["A"].append(5)
```

Useful for: - Graphs - Group Anagrams - Adjacency Lists

------------------------------------------------------------------------

# 8. heapq

``` python
import heapq

nums = [5,2,8,1]
heapq.heapify(nums)
heapq.heappop(nums)
heapq.heappush(nums,10)
```
```text
  Operation   Complexity
  ----------- ------------
  Push        O(log n)
  Pop         O(log n)
  Peek        O(1)
```
Practice: - Kth Largest Element - Merge K Sorted Lists

------------------------------------------------------------------------

# 9. bisect

``` python
import bisect

nums = [1,3,5,7]
bisect.bisect_left(nums,5)
bisect.bisect_right(nums,5)
```

Used for binary search variants.
