# ❓ Why `return` in Palindrome but not in Reverse Array?

## Reverse Array   
DSA/Basic Recursion/6.Reverse_Array_INPLACE.md

```python
arr[i], arr[j] = arr[j], arr[i]
helper(i + 1, j - 1)
```

* Purpose: **Modify the array**.
* No value needs to be returned.
* The recursive call is only doing work (swapping).

✅ No `return` needed.

---

## Palindrome
DSA/Basic Recursion/7.Pallindrome.md

```python
if s[i] != s[j]:
    return False

return helper(i + 1, j - 1)
```

* Purpose: **Return `True` or `False`**.
* The recursive call returns a boolean.
* We must pass that value back.

✅ `return` is required.

---

## Rule to Remember

* **Doing work (print, swap, modify)** → `helper(...)`
* **Returning a value (int, bool, string, list)** → `return helper(...)`

---

## Examples

| Problem          | Return Needed? |
| ---------------- | -------------- |
| Reverse Array    | ❌ No           |
| Print 1 to N     | ❌ No           |
| Sum of N Numbers | ✅ Yes          |
| Factorial        | ✅ Yes          |
| Palindrome       | ✅ Yes          |
