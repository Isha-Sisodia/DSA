# Recursion

## What is Recursion?

Recursion is a programming technique where a function **calls itself** to solve a problem by breaking it into smaller subproblems.

---

## Structure of a Recursive Function

```python
def fun(n):
    # Base Condition
    if condition:
        return

    # Recursive Call
    fun(updated_value)
```

Every recursive function has **2 parts**:
- Base Condition
- Recursive Call

---

## Base Condition

The **base condition** tells the function when to stop calling itself.

Without a base condition, recursion runs forever and causes a **Stack Overflow**.

Example:

```python
def fun():
    fun()
```

This function never stops.

---

## Stack Overflow

Each recursive call is stored in the **Call Stack**.

If the function keeps calling itself without stopping, the call stack becomes full, causing a **Stack Overflow**.

---

## Call Stack Example

```python
fun(3)
```

Calls:

```
fun(3)
 ↓
fun(2)
 ↓
fun(1)
 ↓
fun(0)
```

After reaching the base condition:

```
fun(0) returns
↑
fun(1) returns
↑
fun(2) returns
↑
fun(3) returns
```

---

## Advantages

- Short and clean code
- Easy for Tree and Graph problems
- Used in Merge Sort, Quick Sort, Binary Search, DP

---

## Disadvantages

- Uses extra memory (Call Stack)
- Can cause Stack Overflow
- Slower than loops
- Harder to debug

---

## Key Points

- A recursive function calls itself.
- Every recursion must have a **base condition**.
- Calls are stored in the **Call Stack**.
- Functions return in the **reverse order** of their calls.
