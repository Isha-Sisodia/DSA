# Dynamic Programming (DP) - Memoization

## What is Dynamic Programming?

**Dynamic Programming (DP)** is an optimization technique used to avoid solving the **same subproblem multiple times**.

Instead of recalculating a result, we **store it** and reuse it whenever needed.

This storing process is called **Memoization**.

---

# When Should We Use DP?

Use DP when a problem has:

* ✅ **Overlapping Subproblems**
* ✅ **Optimal Substructure**

---

## 1. Overlapping Subproblems

The same subproblem is solved multiple times.

Example: Fibonacci

```text
fib(5)
├── fib(4)
│   ├── fib(3)
│   └── fib(2)
└── fib(3)
```

Here, `fib(3)` and `fib(2)` are calculated repeatedly.

DP stores these values to avoid recomputation.

---

## 2. Optimal Substructure

The solution of a larger problem depends on the solutions of smaller problems.

Example:

```text
fib(5) = fib(4) + fib(3)
```

---

# How to Identify a DP Problem?

Ask yourself:

* Am I solving the **same recursive call multiple times?**
* Can I **store** the answer and reuse it?
* Can the problem be broken into **smaller subproblems?**

If **YES**, DP is probably applicable.

---

# Memoization (Top-Down DP)

Store already computed answers in a `dp` array.

```python
dp = [-1] * n
```

Here,

```text
-1
```

means **"Not calculated yet."**

---

# Fibonacci using Memoization

```python
class Solution:

    def fibonacciNumbers(self, n):

        dp = [-1] * n
        ans = []

        for i in range(n):
            ans.append(self.fib(i, dp))

        return ans

    def fib(self, n, dp):

        if n == 0:
            return 0

        if n == 1:
            return 1

        if dp[n] != -1:
            return dp[n]

        dp[n] = self.fib(n - 1, dp) + self.fib(n - 2, dp)

        return dp[n]
```

---

# How `dp` Works

Initially:

```text
dp = [-1, -1, -1, -1, -1, -1]
```

Suppose we calculate:

```text
fib(2) = 1
```

Store it:

```text
dp = [-1, -1, 1, -1, -1, -1]
```

Later, if `fib(2)` is needed again:

```python
if dp[2] != -1:
    return dp[2]
```

No recursion is performed.

The stored value is returned immediately.

---

# Complexity

### Normal Recursion

* Time: `O(2ⁿ)`
* Space: `O(n)`

---

### DP (Memoization)

* Time: `O(n)`
* Space: `O(n)`

---

# One-Line Definition

> **Dynamic Programming is an optimization technique that stores the results of previously solved subproblems to avoid repeated calculations.**
