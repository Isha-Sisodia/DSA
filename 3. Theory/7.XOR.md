# XOR (`^`) in DSA

XOR is a bitwise operator in Python:

```python
^
```

### Important Properties

```text
x ^ x = 0
x ^ 0 = x
```

XOR is **commutative and associative**, so order doesn't matter.

### XOR is Cumulative

Means order doesn't matter. We can keep XORing values into one variable:

```python
ans = 0

for num in nums:
    ans ^= num
```

`ans ^= num` means:

```python
ans = ans ^ num
```

So duplicate values cancel each other.

Example:

```text
4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4
```
