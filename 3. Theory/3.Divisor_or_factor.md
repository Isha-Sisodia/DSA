# Finding Divisors of a Number

## Definition

A divisor (or factor) of a number is a number that divides it completely (remainder = 0).
Mathematically - 

```python
n % i == 0
```
means `i` is a divisor of `n`.

If the remainder is `0`, then `i` is a divisor of `n`.

---

## Brute Force

Check every number from `1` to `n`.

```python
for i in range(1, n + 1):
    if n % i == 0:
        print(i)
```

**Time Complexity:** `O(n)`

---

## Optimized Approach

Divisors always occur in pairs.

Example:

```text
36

1 × 36
2 × 18
3 × 12
4 × 9
6 × 6
```

So we only need to check till `√n`.

```python
for i in range(1, int(n ** 0.5) + 1):
    if n % i == 0:
        print(i)

        if i != n // i:
            print(n // i)
```

**Time Complexity:** `O(√n)`

---

## Key Points

- `%` → Check if a number is a divisor.
- `//` → Find the paired divisor.
- Divisors always come in pairs.
- Only iterate up to `√n`.
- Avoid printing the square root twice for perfect squares.
