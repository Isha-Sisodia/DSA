# Reverse Number - Important Notes

## 1. `%` (Modulus Operator)

Used to **obtain the last digit** of a number.

### Syntax

```python
last_digit = n % 10
```

### Example

```python
4567 % 10 = 7
123 % 10 = 3
98 % 10 = 8
```

---

## 2. `//` (Floor Division)

Used to **remove the last digit** of a number.

### Syntax

```python
n = n // 10
```

### Example

```python
4567 // 10 = 456
123 // 10 = 12
98 // 10 = 9
```

---

## 3. `reverse = reverse * 10 + last_digit`

Used to **append the extracted digit to the end of the reversed number**.

### Formula

```python
reverse = reverse * 10 + last_digit
```

### Why multiply by 10?

Multiplying by `10` shifts all existing digits one place to the left, creating an empty space at the end for the new digit.

### Example

```text
reverse = 43
last_digit = 2

43 × 10 = 430
430 + 2 = 432
```

Another example:

```text
reverse = 85
last_digit = 6

85 × 10 = 850
850 + 6 = 856
```

### Easy Way to Remember

- `% 10` → **Get the last digit**
- `// 10` → **Remove the last digit**
- `reverse = reverse * 10 + last_digit` → **Append the extracted digit to the end of the reversed number**
