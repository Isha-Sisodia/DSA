```python
class Solution:
    def isPalindrome(self, n):
  		# code here
  		n = abs(n)  #Important or if n<0: n = -n
  		reverse = 0
  		org = n
  		while n > 0:
  		    last_digit = n % 10
  		    reverse = reverse*10 + last_digit
  		    n = n//10
  		if reverse == org:
  		    return True
  		else:
  		    return False
```
