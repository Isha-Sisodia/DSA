```python
class Solution:
    def remDuplicate(self, arr):
        seen = {}
        result = []
        for num in arr:
            if num in seen:
                seen[num] += 1  # do nothing
            else:
                seen[num] = 1
                result.append(num)
        return result
```

```python
class Solution:
    def remDuplicate(self, arr):
        seen = {}
        result = []
        for num in arr:
            if num not in seen:
                seen[num] = 1
                result.append(num)
        return result
```
