### Method -1
**1. Using the formula with GCD**

The easiest and most efficient approach is:

**LCM(a, b) = (a × b) / GCD(a, b)**

For example, 12 and 18:

GCD = 6

LCM = (12 × 18) / 6 = 36
```python
import math

a = 12
b = 18

lcm = (a * b) // math.gcd(a, b)

print(lcm)
```
or - ```Without using math.gcd()```
```python
a = 12
b = 18

x = a
y = b

while y != 0:
    x, y = y, x % y

gcd = x

lcm = (a * b) // gcd

print(lcm)
```
