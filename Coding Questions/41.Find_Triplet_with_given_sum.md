For this problem, the best approach is **sorting + two pointers**.
### Approach
For every element arr[i], we need to find two other elements whose sum is:
```
target - arr[i]
```
First sort the array. Then use two pointers:

- left = i + 1
- right = n - 1

If the sum is:

- equal to target → True
- smaller → move left
- larger → move right
```python
class Solution:
    def hasTripletSum(self, arr, target):
        arr.sort()
        n = len(arr)

        for i in range(n - 2):
            left = i + 1
            right = n - 1

            while left < right:
                total = arr[i] + arr[left] + arr[right]

                if total == target:
                    return True

                elif total < target:
                    left += 1

                else:
                    right -= 1

        return False
```
