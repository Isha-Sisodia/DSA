Method - 1
```python
class Solution:
    def smallest(self, arr):
        min_num = float("inf")
        n = len(arr)
        for i in range(n):
            min_num = min(min_num,arr[i])
        return min_num
```
Method - 2
```python
class Solution:
    def smallest(self, arr):
        n = len(arr)
        smallest = arr[0]
        for i in range(n):    #we can also start the loop from 1 to n because we have already a[0]
            if arr[i] < smallest:
                smallest = arr[i]
        return smallest
```
