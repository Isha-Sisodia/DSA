### Best approach: HashMap

For every element x, we need:

```needed = target - x```

If needed has already appeared k times, then the current x forms k new pairs.

**Example**

arr = [1, 5, 7, -1, 5], target = 6

---
| Current | Needed | Already seen | New pairs |
| ------- | -----: | -----------: | --------: |
| 1       |      5 |            0 |         0 |
| 5       |      1 |            1 |        +1 |
| 7       |     -1 |            0 |         0 |
| -1      |      7 |            1 |        +1 |
| 5       |      1 |            1 |        +1 |

---
Answer = 3
```python
class Solution:
    def countPairs(self, arr, target):
        freq = {}
        count = 0

        for x in arr:
            needed = target - x

            if needed in freq:
                count += freq[needed]

            freq[x] = freq.get(x, 0) + 1

        return count
```
or
```python
class Solution:
    def countPairs(self, arr, target):
        n = len(arr)
        count = 0
        freq = {}
        for i in range(n):
            needed = target - arr[i]
            if needed in freq:
                count += freq[needed]
            if arr[i] in freq:
                freq[arr[i]] += 1
            else:
                freq[arr[i]] = 1
        return count
```
