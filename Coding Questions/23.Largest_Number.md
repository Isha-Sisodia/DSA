Method - 1
```python
class Solution:
    def largest(self, arr):
        max_num = float("-inf")
        n = len(arr)
        for i in range(n):
            max_num = max(max_num,arr[i])
        return max_num
```
Method - 2
```python
class Solution:
    def largest(self, arr):
        n = len(arr)
        largest = arr[0]
        for i in range(n):
            if arr[i] > largest:
                largest = arr[i]
        return largest
```
