```python
def bubble_sort(arr):
    n = len(arr)

    for i in range(n - 1):            # Number of passes
        for j in range(n - i - 1):    # Adjacent comparisons
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]

    return arr
```
## Bubble Sort

### Theory
Bubble Sort is a simple sorting algorithm that repeatedly compares **adjacent elements** and swaps them if they are in the wrong order. After each pass, the **largest unsorted element "bubbles" to its correct position at the end** of the array. This process continues until the array is completely sorted.

### Algorithm
1. Start from the first element of the array.
2. Compare each pair of adjacent elements.
3. If the left element is greater than the right element, swap them.
4. Continue until the end of the unsorted part of the array.
5. After each pass, the largest element is placed at its correct position.
6. Repeat the process for the remaining unsorted elements until the array is sorted.

#### Stable
- **Yes**

#### In-place
- **Yes**
### Complexity Analysis of Bubble Sort:
- Time Complexity: O(n2)
- Auxiliary Space: O(1)
### Disadvantages of Bubble Sort
- Bubble sort has a time complexity of O(n2) which makes it very slow for large data sets.
- Bubble sort has almost no or limited real world applications. It is mostly used in academics to teach different ways of sorting.
