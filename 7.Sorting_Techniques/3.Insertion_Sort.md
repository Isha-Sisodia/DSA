## Insertion Sort - 
1. Assume the first element is already sorted.
2. Start from the second element ```(i = 1)``` and store it in a variable called key.
3. Compare the ```key``` with the elements in the sorted part (towards the left).
4. While an element is greater than the ```key```, shift that element one position to the right.
5. Insert the ```key``` into the empty position created after shifting.
6. Repeat Steps 2–5 for every remaining element until the entire array is sorted.
```python
a = [12,11,13,5,6]
n = len(a)
for i in range(1,n):
    key = a[i]
    j = i-1
    while j >= 0 and a[j] > key:
        a[j+1] = a[j]
        j -= 1
    a[j+1] = key
print(a)
```

class Solution:
    def insertionSort(self, arr):
        # code here
        n = len(arr)
        for i in range(1,n):
            key = arr[i]
            j = i-1
            while j >= 0 and arr[j] > key:
