# Merge Sort

**Merge Sort** is a **Divide and Conquer** sorting algorithm.

### Core Idea

Instead of sorting the entire array at once:

1.  **Divide** the array into two halves repeatedly.
2.  Continue until each subarray has **1 element**.
3.  A single element is already sorted.
4.  **Merge** the sorted halves by comparing their elements and taking
    the smaller one.
5.  Repeat the merging until the complete array is sorted.

### Example

``` text
[38, 27, 43, 10]

        Divide
       /      \
   [38, 27]  [43, 10]
    /   \      /   \
  [38] [27]  [43] [10]

        Merge
       /      \
  [27, 38]  [10, 43]

       Final Merge
    [10, 27, 38, 43]
```

It works in 3 steps:

## 1. Divide

Split the array into two halves repeatedly.

```text
[5,2,4,1]
    ↓
[5,2] [4,1]
    ↓
[5] [2] [4] [1]
```

## 2. Conquer

Recursively sort the smaller subarrays.

A single-element array is already sorted:

```text
[5] [2] [4] [1]
```

No work is needed here.
So the conquer part is basically trivial in Merge Sort.

## 3. Combine (Merge)

Merge the sorted halves by comparing their elements.

```text
[5] + [2]
  ↓
[2,5]

[4] + [1]
  ↓
[1,4]

[2,5] + [1,4]
  ↓
[1,2,4,5]
```

### Merge Process

Suppose we have two sorted arrays:

``` text
[27, 38]    [10, 43]
```

Compare the first elements:

-   `27` vs `10` → take `10`
-   `27` vs `43` → take `27`
-   `38` vs `43` → take `38`
-   Remaining → `43`

Result:

``` text
[10, 27, 38, 43]
```

### Base Case

If the array has **0 or 1 element**, it is already sorted.

``` python
if len(arr) <= 1:
    return arr
```

### Complexity

-   **Time:** `O(n log n)`
-   **Space:** `O(n)`
-   **Stable:** Yes

### Remember

> **Merge Sort = Divide → Sort → Merge**

The important part is that **merging two already sorted arrays is easy**
because we only need to compare their current elements.

## Method - 1
```python
def merge(left, right):

    result = []

    i = 0
    j = 0

    while i < len(left) and j < len(right):

        if left[i] <= right[j]:
            result.append(left[i])
            i += 1

        else:
            result.append(right[j])
            j += 1

    while i < len(left):
        result.append(left[i])
        i += 1

    while j < len(right):
        result.append(right[j])
        j += 1

    return result


def merge_sort(arr):

    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2

    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    return merge(left, right)


arr = [5, 2, 4, 1]

print(merge_sort(arr))
```
## Method - 2
```python
def merge(a, start, mid, end):

    left = a[start:mid+1]
    right = a[mid+1:end+1]

    i = 0
    j = 0
    k = start

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            a[k] = left[i]
            i += 1
        else:
            a[k] = right[j]
            j += 1
        k += 1

    while i < len(left):
        a[k] = left[i]
        i += 1
        k += 1

    while j < len(right):
        a[k] = right[j]
        j += 1
        k += 1


def merge_sort(a, start, end):

    if start >= end:
        return

    mid = (start + end) // 2

    merge_sort(a, start, mid)     # Divide left half
    merge_sort(a, mid + 1, end)   # Divide right half

    merge(a, start, mid, end)     # Combine


a = [5,2,4,1]
merge_sort(a, 0, len(a)-1)

print(a)
```
