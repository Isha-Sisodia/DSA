## Solid Rhombus
```python
n = 5
for i in range(n):
    print(" " * i + "*" * n)
```
### Output - 
```python
*****
 *****
  *****
   *****
    *****
```
## Hollow Rhombus
```python
n = 5
for i in range(n):
    if i == 0 or i == n-1: 
        print(" " * i + "*" * n)
    else:
        print(" " * i + "*" + " " * (n-2) + "*")
```
### Output - 
```python
*****
 *   *
  *   *
   *   *
    *****
```
