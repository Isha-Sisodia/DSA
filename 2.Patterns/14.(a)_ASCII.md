# ASCII Codes in Python

# What is ASCII?

ASCII stands for **American Standard Code for Information Interchange**.

It is a standard that assigns a unique number to every character.

For example,

Character | ASCII Value
----------|------------
A         | 65
B         | 66
C         | 67
D         | 68
...
Z         | 90

Similarly,

Character | ASCII Value
----------|------------
a         | 97
b         | 98
c         | 99
...
z         | 122

Digits also have ASCII values.

Character | ASCII Value
----------|------------
0         | 48
1         | 49
2         | 50
...
9         | 57

Some special characters

Character | ASCII Value
----------|------------
Space     | 32
!         | 33
@         | 64
\#         | 35
$         | 36
%         | 37

----------------------------------------

# Why do we need ASCII?

Computers do not understand letters.

They only understand numbers.

So internally,

'A' is stored as 65.

'B' is stored as 66.

'C' is stored as 67.

----------------------------------------

# Python Functions

Python provides two important functions.

## 1. ord()

Returns the ASCII value of a character.

Syntax

```python
ord(character)
```

Example

```python
print(ord('A'))
```

Output

```
65
```

Another example

```python
print(ord('a'))
```

Output

```
97
```

Example

```python
print(ord('0'))
```

Output

```
48
```

----------------------------------------

## 2. chr()

Returns the character for an ASCII value.

Syntax

```python
chr(number)
```

Example

```python
print(chr(65))
```

Output

```
A
```

Example

```python
print(chr(97))
```

Output

```
a
```

Example

```python
print(chr(48))
```

Output

```
0
```

----------------------------------------

# ord() and chr() are Opposites

Character

```
'A'
```

↓

```python
ord('A')
```

↓

```
65
```

↓

```python
chr(65)
```

↓

```
'A'
```

# Trick to Remember

Capital A starts at

```
65
```

Lowercase a starts at

```
97
```

Difference

```
97 - 65 = 32
```

Every lowercase letter is 32 greater than its uppercase letter.

Example

```
A = 65
a = 97
```

```
B = 66
b = 98
```

----------------------------------------

# Converting Capital to Small

```python
capital = 'D'

small = chr(ord(capital) + 32)

print(small)
```

Output

```
d
```

----------------------------------------

# Converting Small to Capital

```python
small = 'm'

capital = chr(ord(small) - 32)

print(capital)
```

Output

```
M
```

----------------------------------------

# Getting Next Character

```python
print(chr(ord('A') + 1))
```

Output

```
B
```

Example

```python
print(chr(ord('X') + 1))
```

Output

```
Y
```

----------------------------------------

# Getting Previous Character

```python
print(chr(ord('D') - 1))
```

Output

```
C
```

----------------------------------------

# Why Pattern Questions Use chr(65 + j)

Suppose

```
j = 0
```

```
65 + 0 = 65
```

```
chr(65)
```

Output

```
A
```

Suppose

```
j = 1
```

```
65 + 1 = 66
```

```
chr(66)
```

Output

```
B
```

Suppose

```
j = 2
```

```
65 + 2 = 67
```

Output

```
C
```

Therefore,

```python
chr(65 + j)
```

produces

```
A B C D E F ...
```

----------------------------------------

# Summary

Function | Purpose
---------|--------
ord() | Character → ASCII
chr() | ASCII → Character

Important Values

```
A = 65
Z = 90

a = 97
z = 122

0 = 48
9 = 57

Space = 32
```

Remember

```
ASCII → chr()

Character → ord()
```
