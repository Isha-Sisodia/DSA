or
```python
n = 5
for i in range(1,n+1):
  for j in range(i):
    print(chr(ord('A')+(i-1)), end=" ")
  print()
```
or
```python
n = 5
for i in range(n):
    for j in range(i + 1):
        print(chr(ord('A') + i), end=" ")
    print()
```
