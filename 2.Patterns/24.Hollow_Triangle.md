```python
n = 5
space_1 = n-2
space_2 = 1
for i in range(1,n+1):
    if i == 1: 
        print(" " * (n-1) + "*")
    elif i == n:
        print("*" * (2*n - 1))
    else:
        print(" " * space_1 + "*" + " " * space_2 + "*")
        space_1 -= 1
        space_2 += 2
```

```python
    *
   * *
  *   *
 *     *
*********
```
