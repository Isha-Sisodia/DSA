- This is the last famous pattern from Striver/TUF, and it's different from all the previous ones because we don't print stars or alphabets. Instead, we print numbers based on the distance from the border.
### method  1 - we take index from 1
```python
n = 5
for i in range(1,2*n):
    for j in range(1,2*n):
        top_dist = i-1
        left_dist = j - 1
        right_dist = 2*n-1 - j
        bottom_dist = 2*n-1 - i
        value = min(top_dist,left_dist,right_dist,bottom_dist)
        print(n-value, end = " ")
    print()
  ```
### Method 2 - when we take index from 0
```python
n = 5
size = 2*n-1
for i in range(0,size):
    for j in range(0,size):
        top_dist = i
        left_dist = j
        right_dist = size - 1 - j
        bottom_dist = size - 1 - i
        value = min(top_dist,left_dist,right_dist,bottom_dist)
        print(n-value, end = " ")
    print()
```
