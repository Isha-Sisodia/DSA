### Method 1
```python
n = 5
for i in range(1,n+1):
    start = 65 + (n-i)
    for j in range(start, 65+n):
        print(chr(j), end = " ")
    print()
```
### Method 2
```python
n=5
for i in range(1,n+1):
    for j in range(n-i,n):
        print(chr(65+j),end=" ")
    print()
```
### Method 3
```python
n = 5
for i in range(1, n+1):
    char = chr(ord("A")+(n-i))
    for j in range(i):
        print(char, end = " ")
        char = chr(ord(char) + 1)
    print()
```
