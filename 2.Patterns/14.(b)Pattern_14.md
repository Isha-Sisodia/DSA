```python
# Method 1
n = 5
for i in range(1,n+1):
    for j in range(i):
        print(chr(ord("A")+j), end = "")
    print()
```
```python
#Method 2 
n = 5
for i in range(1,n+1):
    some = 0
    for j in range(i):
        print(chr(ord("A")+some), end = "")
        some += 1
    print()
```
