### Observation
1. There are n rows.
- Row i contains i numbers.
2. The starting number depends on the row:
- Odd row → starts with 1
- Even row → starts with 0
3. After that, the numbers alternate.
``` python
n = 5
for i in range(1,n+1):
    if i % 2 == 0:
        num = 0
    else:
        num = 1
    for j in range(i):
        print(num, end = " ")
        if num == 0:
            num = 1
        else:
            num = 0
    print()
```
