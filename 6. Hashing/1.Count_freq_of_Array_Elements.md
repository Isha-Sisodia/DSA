### Method 1 -  dictionary
```python
#Input: 
nums = [1, 2, 2, 1, 3]
#Output: [[1, 2], [2, 2], [3, 1]]
freq = {}
for num in nums:
    if num not in freq:
        freq[num] = 1
    else:
        freq[num] += 1
# print(freq)
# print(freq.items())    # dict_items([(1, 2), (2, 2), (3, 1)])
ans = []
for key,val in freq.items():
    ans.append([key,val])
print(ans)
```
### Output
```python
[[1, 2], [2, 2], [3, 1]]
```
## Method 2 - Using ```dict.get()```
```python
nums = [1,2,2,1,3]

freq = {}

for num in nums:
    freq[num] = freq.get(num, 0) + 1

ans = []

for key, value in freq.items():
    ans.append([key, value])

print(ans)
```
