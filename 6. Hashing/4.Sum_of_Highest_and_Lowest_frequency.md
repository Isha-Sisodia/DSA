```python
arr = [1, 2, 2, 3, 3, 3]

freq = {}

for num in arr:
    if num not in freq:
        freq[num] = 1
    else:
        freq[num] += 1

max_freq = max(freq.values())
min_freq = min(freq.values())

return max_freq + min_freq
```
