### Important - If multiple elements have the same maximum frequency, return the **smallest** one.
```python
nums = [1, 2, 2, 3, 3, 3]

# Step 1: Count frequencies
freq = {}

for num in nums:
    if num not in freq:
        freq[num] = 1
    else:
        freq[num] += 1

# Step 2: Find maximum frequency
maximum = max(freq.values())

# Step 3: Find the smallest element having maximum frequency
answer = float("inf")

for key in freq:
    if freq[key] == maximum:
        answer = min(answer, key)

print(answer)
```

### If the question changes to:

> **If multiple elements have the same maximum frequency, return the largest element.**

```python
nums = [1, 2, 2, 1, 3]

# Step 1: Count frequencies
freq = {}

for num in nums:
    if num not in freq:
        freq[num] = 1
    else:
        freq[num] += 1

# Step 2: Find maximum frequency
maximum = max(freq.values())

# Step 3: Find the largest element having maximum frequency
answer = float("-inf")

for key in freq:
    if freq[key] == maximum:
        answer = max(answer, key)

print(answer)
```
